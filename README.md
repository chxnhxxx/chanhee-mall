## 지금 바로 켜 보기 (가입 없이)

외부 서비스 키가 하나도 없어도 **데모 모드**(진짜 서비스 대신 흉내 내는 방식)로 모든 화면이 동작합니다.

1. **PowerShell** 을 엽니다. 시작 메뉴에서 "PowerShell" 을 검색하면 나오는, 글자로 명령을 치는 창입니다.
2. 아래 세 줄을 **한 줄씩** 붙여 넣고 Enter 를 누릅니다.

   ```powershell
   cd ~\OneDrive\Desktop\claude\chanhee-mall
   pnpm install
   pnpm dev
   ```

   - 첫 줄: 쇼핑몰 폴더로 이동합니다.
   - 둘째 줄: 쇼핑몰에 필요한 부품을 인터넷에서 내려받습니다. **처음 한 번만** 하면 됩니다(1~3분).
   - 셋째 줄: 쇼핑몰을 켭니다. `✓ Ready` 가 보이면 켜진 것입니다. **이 창을 닫으면 꺼지니 열어 두세요.**

3. 브라우저 주소창에 **http://localhost:3000** 을 입력합니다. (localhost = "내 컴퓨터"라는 뜻)
4. 끌 때는 그 창을 클릭하고 `Ctrl+C` 를 누릅니다.

각 단계의 정상 화면과 오류 해결법은 [실행·구조 안내](docs/RUN_GUIDE.md)에 있습니다. 어렵다면 저에게 "켜 줘"라고 하셔도 됩니다.

**데모 모드에서 알아 둘 것**

- 상품 24개가 미리 들어 있고, 쇼핑몰을 껐다 켜면 장바구니·주문이 **처음 상태로 돌아갑니다.**
- 결제는 "모의 결제" 버튼으로 흉내만 냅니다. 진짜 돈은 오가지 않습니다.
- 주문 확인 메일은 실제로 보내지 않고 PowerShell 창에 글자로 찍힙니다.
- 로그인 화면 아래 "이 계정으로 채우기" 버튼으로 데모 계정(관리자 1개, 고객 1개)을 바로 쓸 수 있습니다.

## 주요 화면

| 주소                        | 화면                                     |
| --------------------------- | ---------------------------------------- |
| `/ko`                       | 홈                                       |
| `/ko/products`              | 상품 목록·카테고리·검색                  |
| `/ko/cart` → `/ko/checkout` | 장바구니 → 배송지 입력 → 결제            |
| `/ko/orders`                | 내 주문                                  |
| `/ko/admin`                 | 관리자(매출·주문·상품 관리, 한국어 전용) |
| `/en`                       | 영어 화면 (헤더의 언어 버튼으로도 전환)  |

전체 주소 목록과 폴더 구조는 [실행·구조 안내 7~8장](docs/RUN_GUIDE.md#7-주요-화면-주소)을 보세요.

## 이 쇼핑몰의 안전장치 (요약)

- 결제 금액은 손님 화면이 보낸 값을 믿지 않고, 서버가 데이터베이스 가격으로 다시 계산해 비교합니다.
- 같은 결제가 두 번 반영되지 않게 막고, 30분 동안 결제하지 않은 주문은 자동 취소 후 재고를 되돌립니다.
- 토스가 보내는 결제 알림도 그대로 믿지 않고 토스에 다시 물어서 확인합니다.
- 비밀 키는 서버에서만 쓰며, 토스 키가 `test_` 로 시작하지 않으면 쇼핑몰이 아예 켜지지 않습니다.
- 로그인·검색을 짧은 시간에 너무 많이 하면 잠시 막습니다.

자세한 설명은 [코드 리뷰 안내서](docs/REVIEW_GUIDE.md)에 있습니다.
